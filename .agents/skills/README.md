# FrameScope Android agent skills

These project-local skills were installed with Google's official Android CLI from the Android Skills catalog:

- `android-cli`
- `testing-setup`
- `android-profiler`
- `r8-analyzer`
- `edge-to-edge`
- `android-intent-security`
- `adaptive`
- `navigation-3`

Upstream: https://github.com/android/skills

The skill directories are generated by `android skills add <skill> --project=. --agent=codex`. Keep upstream skill contents intact when refreshing them; use the Android CLI rather than hand-editing vendored skill/reference files.
